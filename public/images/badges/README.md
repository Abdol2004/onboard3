# Badge Images - AI Generation Prompts

This directory contains badge images for the ONBOARD3 gamification system.

## How to Generate Badge Images

Use these prompts with AI image generators (DALL-E, Midjourney, Stable Diffusion, etc.) to create professional medal/badge images:

### General Style Guidelines
- **Format:** PNG with transparent background
- **Size:** 512x512 pixels minimum
- **Style:** Photorealistic 3D rendered medal/badge
- **Lighting:** Dramatic lighting with metallic sheen
- **View:** Straight-on view, slightly tilted for depth

## File Naming Convention
Save each generated image with the exact filename shown above (e.g., `citizen.png`, `quest_master.png`, etc.)

## Alternative: Using Midjourney
If using Midjourney, append to each prompt:
```
--ar 1:1 --v 6 --style raw --quality 2
```

## Alternative: Using DALL-E 3
Use the prompts as-is, DALL-E will handle transparent backgrounds automatically.

## Quick Generation Tips
1. Generate all role badges first (most important)
2. Then achievement badges
3. Finally milestone badges
4. Ensure consistent lighting and style across all badges
5. Keep metallic sheen and 3D depth consistent
